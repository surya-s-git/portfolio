Weather GPT — Generative AI Weather Assistant

🌦️ Project Overview

Weather GPT is a Generative AI-powered weather assistant designed to help users interact with weather information through a conversational interface. The website combines a chat interface with weather details, forecasts, and AI-generated insights to make weather information easier to understand.

✨ Features

- Conversational Weather Assistant: Ask weather-related questions using natural language.
- Weather Dashboard: View current weather conditions and related information.
- Weather Forecast: Explore forecast information for upcoming hours.
- AI-Powered Insights: Get helpful weather-related suggestions and insights.
- User-Friendly Interface: Chat interface with suggested questions for quick access.
- Weather Information Display: View details such as temperature, humidity, wind speed, and visibility when available.
